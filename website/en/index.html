PDFSee

Free & Open Source

Local processing, documents stay on your machine. A lightweight, cross-platform PDF tool for reading, merging, splitting, extracting pages, and format conversion. No registration, just open and use.

  • Read PDF · Thumbnails · TOC · Search
  • Merge · Split · Extract pages
  • Image to PDF · Document to PDF
  • macOS & Windows
Download Latest View source on GitHub
01

Read PDF Search & Copy

Select or drag in local PDF files to view thumbnails and outline structure. Search text, copy content, jump to pages, zoom, rotate views, or export the current page as PNG. Encrypted PDFs can be opened with a password.

02

Merge PDF Combine Files

Add multiple PDF files, drag to reorder, and export as one merged file. Organize contracts, reports, or study materials without online services.

03

Split PDF By Page Count

Set the number of pages per file to split long documents into smaller ones. Support specifying page ranges, outputting to a new folder in your chosen directory.

04

Extract Pages Reorder & Rotate

Enter 1-3, 5, 8-6 to select forward and reverse ranges, enter 3,1,2 to reorder pages. Omit page numbers to delete pages, and rotate exported pages as needed.

05

Image to PDF Document to PDF

Convert JPG and PNG images to PDF in specified order, with options for image size, A4, or Letter page formats. Word, Excel, PowerPoint and other documents can also be converted to PDF — requires LibreOffice installed locally.

Supported Input Formats

PDF .pdf Images .jpg, .jpeg, .png Word .doc, .docx Excel .xls, .xlsx PowerPoint .ppt, .pptx OpenDocument .odt, .ods, .odp RTF .rtf Plain Text .txt

Document to PDF conversion requires LibreOffice installed locally. Layout results depend on LibreOffice and system fonts.
